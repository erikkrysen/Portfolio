# Erik Krysén — Portfolio

My personal portfolio, live at **[krysen.se](https://krysen.se)**.

The site is laid out like a file cabinet. Each section is its own folder (home, projects, design, photography, about and contact) that you flip through as you scroll. The contact folder is an envelope that opens on a desk covered in scattered mail.

## Built with

- [React 19](https://react.dev) (Create React App)
- [Typed.js](https://github.com/mattboldt/typed.js) for the typing effect
- Plain CSS, one stylesheet per component
- Hosted on GitHub Pages

## Structure

```
src/
  App.js         # stacks the folders in order
  Home/ About/ Contact/ Design/ Photo/   # one folder per section
  components/    # Navbar, project list, buttons, shared bits
  images/        # photography and project images
  fonts/         # Karrik and Outward webfonts
```
